# Relay Project Changelog

## Purpose

This changelog records meaningful project-level changes to Relay's specifications, plans, and decisions. It complements those documents; it does not replace or repeat them.

## Versioning and dates

Entries use a simple project-document version and the date the change was recorded, in `YYYY-MM-DD` format. This is not a software release history.

## 0.1.0 — 2026-11-06

Initial project baseline.

### Added

- Root Product Specification defining Relay V1 scope, functional requirements, business rules, acceptance criteria, and open decisions.
- Development roadmap sequencing product delivery, dependencies, milestones, verification, integration, and deployment stages.

### Changed

- None.

### Fixed

- None.

### Decisions

- Established the root product specification as the authority for V1 requirements.
- Recorded confirmed product behavior and identified unresolved decisions explicitly rather than assuming answers.

## Guidelines for future entries

- Add new entries in reverse chronological order so the latest change appears first.
- Use a new version and the date the project-level change is recorded.
- Record only meaningful changes to product scope, requirements, plans, or decisions.
- Summarize the change under **Added**, **Changed**, **Fixed**, or **Decisions**; omit categories with no entries when adding future versions.
- Keep each entry concise, state the outcome, and reference the relevant project document when useful.
- Do not record implementation details, routine edits, or changes that do not affect project-level understanding.
- Do not rewrite prior entries to imply history that was not recorded.
